# Análise de Anúncios de Venda de Carros

Este aplicativo web permite explorar dados de anúncios de venda de carros nos EUA, direcionado para vendedores e para compradores. Por meio dele, os compradores poderão comparar preços e os vendedores poderão entender melhor o mercado.

## Funcionalidades

O aplicativo possui checkboxes para mostrar e esconder os seguintes gráficos:
- Histograma da quilometragem
- Gráfico de dispersão entre quilometragem e preço

Dessa forma, vendedores e compradores poderão clicar na caixa de seleção desejada e visualizar o gráfico de seu interesse.
